# Third-party source

`vendor/skyscanner` contains the Python client from
https://github.com/irrisolto/skyscanner at
`cb0946b2f6107128ee7968ec4525e4f167dd4945`.

Its original GPL-3.0 license is retained at `vendor/skyscanner/LICENSE.md`.
The repository root MIT license does not replace the vendored code license.
The client source is unchanged; upstream examples and APK archives are omitted.

The integration was informed by the existing project-local MCP setup at
https://github.com/shadyvb/mcp-skyscanner, revision
`331352f41dc2bd3623680a91889c67822c3a96e6`.
